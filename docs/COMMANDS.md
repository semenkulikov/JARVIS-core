# Голосовые команды

Сначала «Джарвис», hey Jarvis или два хлопка. После ответа имя можно не повторять 7 секунд, после вопроса — 10. Тишина закрывает это окно. Слабые и пустые фразы отбрасываются. Совпадение с командами нечёткое, но команды с действием в системе не берутся «на глаз» из произвольной фразы.

## Статус и короткие реплики

| Что | Примеры |
|---|---|
| Полный статус | «статус», «статус по задачам», «отчёт», «доклад», «сводка», «что по задачам» |
| Задачи и планы | «что у меня на сегодня», «чё по планам», «что сегодня», «какие планы», «планы на сегодня» |
| Питание | «сколько белка», «сколько калорий», «что по еде», «что по питанию» |
| Проекты | «как деплой», «что по проектам», «что с деплоем» |
| Время | «который час», «время», «сколько времени» |
| Тренировка | «когда тренировка», «тренировка» — только если заданы ваши дни и время |

Короткие реплики без сервера: «доброе утро», «добрый день», «добрый вечер», «спокойной ночи», «привет», «как дела», «как ты», «спасибо», «молодец», «ты тут», «ты здесь», «кто ты», «пока», «хорошо», «понятно», «у меня всё хорошо».

Приветствие и прощание частично зависят от времени суток. Статус в эти ответы не подмешивается. Полный список фраз — словарь `SMALLTALK` в `src/jarvis_voice.py`.

## Локальные команды

| Группа | Примеры и результат |
|---|---|
| Повтор | «повтори», «что ты сказал», «ещё раз», «помедленнее», «повтори помедленнее» |
| Звук | «громче», «тише», «громкость на тридцать», «выключи звук», «включи звук». Звук включается и выключается явно, а не переключается |
| Медиа | «пауза», «продолжи», «играй», «следующий», «предыдущий» |
| Экран | «выключи экран», «погаси экран», «заблокируй компьютер» |
| Окно | «закрой окно», «закрой активное окно». Программа может спросить, сохранять ли файл |
| Снимок | «сделай скриншот», «снимок экрана» → `runtime/screenshots/` |
| Система | «заряд», «батарея», «температура», «сколько свободно на диске» |
| Открыть | «открой браузер», «открой ютуб», «открой курсор», «открой телеграм» |
| Проекты | «открой проект …», «открой гитхаб». Приложение или каталог должны существовать |
| Git, только чтение | «что в гите проекта …», «последний коммит проекта …» |
| Буфер | «прочитай буфер», «прочитай буфер обмена». Текст не пишется в кэш WAV и в обычный журнал синтеза |
| Заметки | «запиши идею …», «сохрани заметку …» → `notes.md` |
| Таймер | «таймер на пять минут», «поставь таймер на один час тридцать минут» |
| Повтор | «каждые сорок пять минут напоминай встать» |
| Отмена | «отмени таймер», «отмени напоминания», «отмени все таймеры и напоминания» |
| Фокус | «режим фокуса» — пауза музыки и таймер перерыва. Звук отдельных мессенджеров не трогает |
| Сон | «режим сна» — пауза, без звука, экран гаснет, компьютер блокируется |
| Тренировка | «режим тренировки» — воспроизведение или заданный список, таймер подхода, вода |
| Выключение | «выключи через десять минут», затем отдельное «да» или «подтверждаю» в окне продолжения. Уверенность распознавания не ниже 0,8 |
| Отмена выключения | «отмени выключение» → `shutdown /a` |
| Тишина | «не беспокоить», «режим тишины». Обратно: «можно беспокоить», «выключи режим тишины» |

Таймеры и напоминания сохраняются между запусками. У режима свои таймеры. Смена режима не удаляет обычные таймеры.

## Через свой сервер

- «добавь задачу …» → вид `todoist_add`. Создаёт ли сервер задачу в Todoist, решает сервер.
- «переведи буфер на английский» или «на русский» → `clipboard_translate`.
- «кратко перескажи буфер» → `clipboard_summary`.
- «добавь двести грамм творога» → `food_log`. Если порция неоднозначна, сервер спрашивает подтверждение в чате.
- Остальные вопросы → вид `free`: календарь, задачи, питание и проекты в пределах вашего сервера.

Текст из `outbox` озвучивается. Как код он не выполняется. Отправка сообщений, удаление, миграции, ветки и запросы на слияние подтверждаются в чате на стороне сервера. Проверки говорящего нет. В Telegram помощник сам ничего не отправляет.

## Остановить речь

«Заткнись», «замолчи», «замолкни», «шат ап», «шадап», «хватит», «стоп», «тихо», «помолчи», «умолкни», «довольно», «отставить».

После остановки — короткая реплика: «Как скажете, сэр», «Как прикажете», «Умолкаю, сэр» или «Ладно, сэр». Новая команда с именем в начале прерывает текущую речь. Объявления ждут своей очереди.
