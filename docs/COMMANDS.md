# Голосовые команды

Сначала «Джарвис» / hey Jarvis или два хлопка. После ответа имя можно не повторять
7 секунд (10 секунд после вопроса). Тишина закрывает окно; слишком слабые/пустые фразы отбрасываются.
Распознавание нечёткое, но команды с системными последствиями не получают произвольный fuzzy-match.

## Статус и короткие ответы

| Что | Примеры |
|---|---|
| Полный статус | «статус», «статус по задачам», «отчёт», «доклад», «сводка», «что по задачам» |
| Задачи/планы | «что у меня на сегодня», «чё по планам», «что сегодня», «какие планы», «планы на сегодня» |
| Питание | «сколько белка», «сколько калорий», «что по еде», «что по питанию» |
| Проекты | «как деплой», «что по проектам», «что с деплоем» |
| Время | «который час», «время», «сколько времени» |
| Тренировка | «когда тренировка», «тренировка» — только если заданы ваши дни/время |

13 групп small talk, 34 варианта реплик: «доброе утро», «добрый день», «добрый вечер»,
«спокойной ночи», «привет», «как дела / как ты», «спасибо», «молодец», «ты тут / ты здесь»,
«кто ты», «пока», «хорошо / понятно», «у меня всё хорошо».
Приветствие/прощание частично учитывает время суток. Статус не подмешивается в small talk.
Все точные варианты приведены в `SMALLTALK` в `src/jarvis_voice.py`.

## Быстрые локальные команды

| Категория | Примеры и результат |
|---|---|
| Повтор | «повтори», «что ты сказал», «ещё раз», «помедленнее», «повтори помедленнее» |
| Звук | «громче», «тише», «громкость на тридцать», «выключи звук», «включи звук»; mute — установка состояния |
| Медиа | «пауза», «продолжи», «играй», «следующий», «предыдущий» |
| Экран | «выключи экран», «погаси экран», «заблокируй компьютер» |
| Окно | «закрой окно», «закрой активное окно»; приложение может спросить о сохранении |
| Снимок | «сделай скриншот», «снимок экрана» → `runtime/screenshots/` |
| Система | «заряд», «батарея», «температура», «сколько свободно на диске» |
| Открыть | «открой браузер», «открой ютуб», «открой курсор», «открой телеграм» |
| Проекты | «открой проект <название>», «открой гитхаб»; приложения/каталог должны существовать |
| Git, read-only | «что в гите проекта <название>», «последний коммит проекта <название>» |
| Буфер | «прочитай буфер», «прочитай буфер обмена»; содержимое не сохраняется в WAV-кэш/обычный текстовый TTS-log |
| Идеи | «запиши идею <текст>», «сохрани заметку <текст>» → локальный `notes.md` |
| Таймер | «таймер на пять минут», «поставь таймер на один час тридцать минут» |
| Повторяющиеся | «каждые сорок пять минут напоминай встать» |
| Отмена | «отмени таймер», «отмени напоминания», «отмени все таймеры и напоминания» |
| Фокус | «режим фокуса» — пауза музыки и таймер перерыва, не mute отдельных мессенджеров |
| Сон | «режим сна» — пауза, mute, экран off и lock |
| Тренировка | «режим тренировки» — медиа/настроенный playlist, таймер подхода, вода |
| Выключение | «выключи через десять минут» → вопрос; отдельное «да / подтверждаю» в follow-up, уверенность ≥0.8 |
| Отмена выключения | «отмени выключение» → `shutdown /a` |
| DND | «не беспокоить», «режим тишины»; обратно «можно беспокоить», «выключи режим тишины» |

Таймеры/напоминания сохраняются между перезапусками. У режима свои таймеры;
переключение режима не удаляет обычные таймеры пользователя.

## Через внешний сервер

- «добавь задачу <текст>» → `todoist_add`; сервер решает создание Todoist-задачи.
- «переведи буфер на английский / русский» → `clipboard_translate`.
- «кратко перескажи буфер» → `clipboard_summary`.
- «добавь двести грамм творога» → `food_log`; при неоднозначности нужно подтверждение в чате.
- Остальные вопросы/действия → `free`: календарь, задачи, питание, проекты — по возможностям сервера.

Текст outbox озвучивается, а не выполняется как код. Рискованные серверные действия
(отправка сообщений, удаление, миграции, ветки/PR и т. п.) требуют подтверждения в чате
на стороне сервера. VPN, реальная voice-ID и отправка в Telegram в проект не входят.

## Прервать

«Заткнись», «замолчи», «замолкни», «шат ап», «шадап», «хватит», «стоп», «тихо»,
«помолчи», «умолкни», «довольно», «отставить». После остановки — короткий ack:
«Как скажете, сэр», «Как прикажете», «Умолкаю, сэр» или «Ладно, сэр».
Новая команда с ведущим именем во время речи прерывает текущую; уведомления ждут очереди.
