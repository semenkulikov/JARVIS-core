# Распознавание команд: сравнение

`scripts/eval_asr.py` озвучивает 24 команды и 10 свободных вопросов четырьмя голосами Silero (136 клипов, лёгкий шум) и прогоняет их через распознаватели. Голоса синтетические, поэтому цифры сравнивают распознаватели между собой, а не с живым микрофоном. Команда считается понятой, если текст ведёт к той же локальной команде, что и эталон. Для свободных вопросов считается, сколько из них превратились бы в команду.

Замер 10 ноября 2026, ноутбук на Windows 11, Vosk small-ru-0.22, faster-whisper 1.2.1.

| Вариант | Команды | Свободные вопросы → команда | Время после конца речи, p50 / p95 | Нагрузка (RTF) |
|---|---|---|---|---|
| Vosk свободный, прежние шаблоны | 71/96 | 0/40 | 18 / 43 мс | 0,17 |
| Vosk свободный, шаблоны с вариантами окончаний | 91/96 | 0/40 | 18 / 43 мс | 0,17 |
| Vosk с грамматикой команд, сам по себе | 88/96 | 1/40, остальные — мусор с уверенностью до 1,0 | 5 / 7 мс | 0,02 |
| Свободный + грамматика для безопасных команд | 93/96 | 0/40 | без изменений: грамматика уже работает параллельно | +0,02 |
| faster-whisper base, int8, CPU | 46/96 | 0/40 | 532 / 569 мс | 0,23, загрузка 39 с |

Выводы:

- Главный выигрыш дали шаблоны: Vosk часто слышит «выключения», «перескажу», «задача», «на диски», «миграцией». Теперь эти формы принимаются.
- Распознаватель с грамматикой нельзя ставить вместо свободного: любой звук он превращает в фразу из списка. Его вариант принимается только для команд без последствий (`GRAMMAR_SAFE` в `src/jarvis/core/quick.py`), только вне окна продолжения и только если свободный текст похож на него (отношение от 0,6). Запись еды, заметки, задачи, режимы, закрытие окна и выключение так не срабатывают.
- faster-whisper base хуже на коротких командах, добавляет полсекунды на каждую фразу и требует отдельной среды на 281 МБ плюс модель. Не используется.
- В словаре Vosk нет слов «реквест», «перескажи» и «еще» (только «ещё»). Говорите «открой пиар» или «запрос на слияние».

## Запись своего голоса

Синтетический голос не заменяет настоящий. `scripts/calibrate_voice.py` за 5–7 минут записывает
владельца: 10 раз «Джарвис» с разного расстояния и громкости, 40 команд из каталога (сначала те,
что ошибались), 10 фраз «Джарвис … команда» с естественной паузой и 30 секунд фона комнаты.
Слушатель на это время приостановлен, поэтому команды не выполняются. Клипы и `manifest.json`
лежат в `<home>/calibration/<время>/` и не попадают в репозиторий.

```powershell
python scripts\calibrate_voice.py --home C:\Jarvis\voice
```

Оценка записей — `scripts/eval_calibration.py`: каждый клип проходит настоящий путь слушателя
(кандидат имени из грамматики Vosk и openWakeWord, свободная проверка имени, проверка голоса,
захват фразы двумя распознавателями, `Router.choose`, `match_alias`). Фон комнаты нарезается на
окна для чужих оценок голоса и прогоняется через активацию: ложных срабатываний быть не должно.
`--set ключ=значение` сравнивает настройки, `--enroll путь` пишет пробный профиль голоса из
половины клипов (вторая половина остаётся проверочной). Результаты — `eval-<метка>.json` рядом с
записями.

```powershell
python scripts\eval_calibration.py --home C:\Jarvis\voice --label after
python scripts\eval_calibration.py --home C:\Jarvis\voice --label old --set wake_verify_normalize=false
```

Записи владельца 10.11.2026 (61 клип, ноутбук на столе, разное расстояние):

| | 3.20.0 | 3.21.0 |
|---|---:|---:|
| Активация («Джарвис» и «Джарвис … команда») | 13 из 20 | 15 из 20 |
| Только «Джарвис» | 4 из 10 | 6 из 10 |
| Команды, включая фразы после имени | 34 из 50 | 43 из 50 |
| Ложные активации на 30 с фона | 0 | 0 |
