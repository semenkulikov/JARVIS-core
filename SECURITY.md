# Безопасность

## Куда писать

Уязвимость сообщайте письмом на [saifutdinov2006@mail.ru](mailto:saifutdinov2006@mail.ru). Публичную задачу и запрос на слияние не создавайте: в переписке будут детали, которые до исправления лучше не публиковать.

В письме укажите версию (`3.26.3` или хеш коммита), что происходит и как это повторить. Ответ — в течение 7 дней. Исправление публикуется в истории изменений и новым тегом.

## Правила

- В Git не попадают настройки, секреты, журналы, кэш, `outbox/`, заметки, снимки экрана, модели, звук и виртуальное окружение. Список — в `.gitignore`.
- Секрет не пишите в адрес, в URL удалённого репозитория и в аргументы командной строки. Диспетчер учётных данных Windows используется только для записей `JarvisVoiceAssistant.*`.
- Имя «Джарвис» и фраза «да» при выключении не проверяют, кто говорит. Запись и чужой голос могут запустить помощника. Необязательная проверка голоса владельца снижает этот риск, но защитой не является.
- Закрытие окна, блокировка, выключение звука и выключение компьютера выполняются по-настоящему. Протокол «бобик сдох» без вопросов закрывает все окна пользователя (программа с несохранённым файлом может спросить сама) и блокирует компьютер.
- Личные шаги протоколов с путями и адресами держите в `protocols_local_file` (по умолчанию `secrets/protocols.local.json` в рабочем каталоге). Файлы `secrets*` и `*.local.json` в `.gitignore`; содержимое этого файла не пишется в журнал.
- Чтение буфера вслух остаётся на компьютере. Команды «переведи буфер» и «перескажи буфер» отправляют выбранный текст на ваш сервер.
- Папка `outbox/` содержит только текст для озвучки. Эти файлы не запускаются как код или команда оболочки.
- Модели скачивайте с сайтов, указанных в [docs/SETUP_WINDOWS.md](docs/SETUP_WINDOWS.md). Пакеты Torch могут содержать исполняемый код.
- Если секрет уже попал в репозиторий, сначала отзовите его у сервиса. Новый коммит не стирает значение из истории Git.

`python scripts/scan_tree.py` ищет типичные следы секретов в дереве файлов. Перед публичным выпуском просмотрите ещё и историю коммитов.
